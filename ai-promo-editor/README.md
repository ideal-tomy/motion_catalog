# AI PROMO STUDIO — ブラウザ編集コア

設計実装セットのStep 1・Step 2に、**v3の図鑑・素材サムネイル・12レイアウト・直接編集**を追加したローカル編集アプリです。動画構成JSONを正本とし、Remotion Playerでその場で確認します。既存 `promo-studio/` の動画生成環境とは別プロジェクトです。

## v3の操作

1. 「動き」→「モーションを探す」。60枚の静止サムネイルから選んだ1件だけが原本Canvasで再生されます。4件だけ「選択レイヤーに試着」可能。見本再生・シーン適用・MP4出力を区別しています。
2. 「素材」で画像・動画をアップロード。実画像・動画ポスターをクリックすると拡大します。選択セル・選択フレーム・背景・追加レイヤーへ配置できます。サムネイルとメタデータも保存されます。
3. コマを選び、右の「12種類から画面構成を選ぶ」。中央表示と「変更前を表示」で比較し、採用またはキャンセル。余った素材は保留トレイに残ります。
4. 「編集モード」でドラッグ、四隅の拡縮、上のハンドルで回転。「形状・切り抜き」で円・楕円・ひし形を選び、素材タブの「選択フレームに入れる」で実際にクリップできます。右でcover/contain、切り抜き位置、字体・文字色、透明度、重ね順を調整します。
5. スナップは1%／5度、Altで解除、Shiftで縦横比固定。編集領域にフォーカス中のDeleteは削除（Undo可能）。複製、最前面／最背面、中央揃え、横の中心の等間隔、ロック／非表示も右側から操作できます。
6. 「再生モード」では編集枠を表示せず、フレーム駆動の映像を再生します。編集モードは全レイヤーの配置確認用に動き・表示時刻を停止します。編集後は保存。Undo/Redo・再読込・保存履歴を継続利用できます。

v3詳細：[現状監査](docs/EXTENSION_V3_AUDIT.md) / [実装・制約](docs/EXTENSION_V3_IMPLEMENTATION.md) / [操作検証](docs/EXTENSION_V3_TEST.md)。依存パッケージの追加はありません。MP4・共有HTML出力は引き続き未実装です。

## 起動

このPCでは依存導入済みです。PowerShellでこのフォルダを開きます。

```powershell
# 初回・別PCのみ（Node.js 22とnpmが必要）
npm ci
# 通常の起動
./起動.ps1
# ブラウザで http://127.0.0.1:4319 を開く
```

ログを見ながら起動する場合は `npm run dev`。停止はそのターミナルでCtrl+C。`起動.ps1` は補助プロセスを非表示で起動し、ログとPIDをworkspace/logs/に保存します。外部公開・認証なしのネットワーク待受はしません。

非表示起動を停止する場合は `./停止.ps1`。保存してから実行してください。アプリ名・待受ポート・PIDを確認し、今回のプロセスだけを停止します。

## 使い方

1. 付属の20秒・4コマ初稿が開きます。これは素材・実機能のない例示データです。
2. 左のコマか下のタイムラインを選択。右で秒数、1/2/4分割・自由配置、文字、色、位置、透明度、重ね順、緩急を変更します。
3. 秒数は整数フレームに丸めます。7→9秒は総尺22秒へ伸長。20秒維持を選ぶと再配分案が開き、承認まで反映しません。レイヤーの時間を勝手に短縮しないので、コマからはみ出す場合は警告を確認してください。
4. 素材タブで画像・動画・音声をアップロードし、選択コマへ配置。セルはレイヤーごとに指定します。レイアウト切替で素材は削除されません。
5. 手動編集した値はAIの部分修正から保護。固定も可能です。AIには選択コマの依頼JSONを渡し、返されたpatchを読み込み、変更前後を見て承認・一部採用します。AI APIは呼び出しません。
6. 保存でJSONと履歴をディスクに保存。Undo/Redoは編集中の履歴、左の保存履歴は過去保存版の復元です。保存前に閉じると未保存変更の警告が出ます。

## 保存先と正本

```text
workspace/projects/<projectId>/
  project.json      正本。画面と同じ構成
  history/<revision>.json
  assets/          アップロード素材
```

JSON出力は構成だけのダウンロードです。素材付き案件のバックアップはプロジェクトフォルダごとコピーしてください。単体JSONの素材付き別プロジェクトへのインポートは、素材を取り違えないよう今回未対応です。アプリ内のプロジェクト複製は素材もコピーします。

- Undo/Redo、原子的保存、保存履歴、保存のrevision競合検出

## 次の段階

MP4・共有HTML出力、Playerとの動画一致検査、4件のMP4検証、配色の自動候補、AI自動呼び出し、デモの自動撮影はまだ実装していません。今回の編集ではレンダリングを行いません。実装済みアダプターの時間や速度の意味を安定させてから、同じCompositionをRendererへ接続します。

## 検証

```powershell
npm test
npm run build
# ローカルアプリ起動中に実行
npm run test:browser
```

ブラウザ検査はこのPCにあるPlaywrightとEdgeを使用します。別PCではtests/browser.cjsのPlaywright参照先を調整してください。検査は付属サンプルで行い、最後に内容を元の状態へ新しいrevisionとして戻します。検査履歴と素材は復旧できるよう保持します。
