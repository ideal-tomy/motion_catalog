# 枠なし制作・配色・素材の見せ方 / v0.5.0

全画面で使う素材が背景色の下へ潜る問題と、停止中の再生位置・右側のコマ設定がずれる問題を修正。描画順は保存済みの重ね順を並べたうえで安全なインデックスに変換し、負の重ね順でも背景色の下へ落ちない。

## 操作

1. 画像・動画レイヤーを選び、右側「素材の見せ方」で「枠なし・全画面／枠なし・自由配置／角丸カード／ブラウザ枠／円・楕円／斜めの切り抜き」を選ぶ。編集表示へ切り替わり、その場で見た目が変わる。
2. 「枠なし・全画面」は角丸・枠・影を外してコマ全体へ広げ、文字の後ろに置く。既に配置されている同じ素材へ「背景に設定」してもレイヤーを重複追加しない。元素材と他レイヤーは保持する。
3. 「素材の拡大率」と切り抜き横・縦位置で、素材の中の注目部分へ寄る。レイヤーの枠の寸法と、素材内の拡大・注目位置は別々に調整できる。
4. レイヤー一覧から背景・画像・動画・文字を選び、既存の移動・サイズ・回転・重ね順・透明度・動きを個別に編集する。フレーム付き表示を選んだ場合だけ影やブラウザのバーを描く。
5. 全体の配色は「コマの上書き色にも反映」を初期ONとした。固定中のコマ・レイヤーと意図的な個別色は保持し、同じテーマ色を直接指定していた文字は色トークンへつなぎ直す。チェックを外すとコマの独自配色を維持できる。
6. 再生位置を動かすと、編集／停止／再生のいずれでも対象コマと設定欄が同期する。変更は保存後に再読込しても維持される。

## 映像と編集画面の区別

選択線・操作ハンドル・空セルのガイドは編集専用。分割セルのガイド枠を再生映像に常時入れない。枠なし全画面が基本で、カードやブラウザ枠は場面ごとに明示的に選ぶ。

焼き込み済みの画像・MP4の背景色、文字、元画面のUI枠は全体配色で変更・除去されない。素材内の拡大・切り抜き、必要に応じた元素材の再抽出で構図を整える。完成MP4を取り込んでも元レイヤーには分離されない。素材付き編集サンプルは完成CMの復元ではなく、別レイヤーで構成した操作確認例。

動画制作時の方針もルートAGENTS.mdへ追記した。全景のスクリーンショットを枠へ当てはめるだけで終えず、全画面・再構図・切り抜き・重なりを選び、元素材と文字を独立して保持する。
