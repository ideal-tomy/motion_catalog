# ライブ試着と動画編集 — 2026-11-13 / v0.4.0

現在の配色・全画面・フレーム・レイヤー編集の追加修正は [PRESENTATION_EDITING.md](PRESENTATION_EDITING.md)（v0.5.0）を参照。以下はv0.4.0時点の実装記録。

## 起きていた問題

図鑑は原本Canvasの60種を再生できたが、編集Compositionは4種類しか受け付けず、試着時は45フレームへ移動して停止していた。42fの登場演出は既に終わっており、選択しても静止して見えた。また編集モードは配置確認のため全モーションを停止していた。完成MP4を編集プロジェクトとして取り込む入口もなかった。

## 今回の動作

1. 全60 IDをScene/LayerのmotionStackへ保存できる素材用アダプターへ接続。
2. 適用先をコマ全体／選択レイヤーから指定。レイアウトと動きを未確定のまま組み合わせ、対象コマを0fから自動ループ。採用で履歴へ追加、取消で元の構成へ。
3. 右のコマ全体・レイヤーの動きからも選択可能。コマ演出の秒数・速度を調整して再確認できる。「このコマを再生」は編集モードからも使える。全編再生は作品の0秒から。
4. 既存の素材・文字・フォント・マスク・正規化座標へCSS/SVGのフレーム駆動効果を適用。Canvas見本の固定文字・背景は編集映像へ貼り付けない。
5. 完成動画ライブラリの6作品から別プロジェクトを作成。元MP4をコピーし、音声も維持。コマ分割・トリム・速度・音量・文字追加・マスク・動きの追加が可能。
6. 画像・文字・BGMが独立した20秒DDサンプルを生成。完成動画の復元ではなく、既存の実画面撮影素材を使う再構成例。架空データを含むデモで、実案件の結果ではない。
7. 直接アップロードしたMP4も全尺の新規コマへ配置できる。動画の開始位置と使用尺は秒で操作でき、元のファイルを上書きしない。

## 図鑑と素材用版の違い

元の図鑑は、指定の文字・図形・チャート・背景で作る演出見本。編集用版はユーザーのレイアウトや素材を保つためのアダプターであり、原本の完成画面を完全複製するものではない。

|ID群|素材への作用・制約|
|---|---|
|001–004、017–024|実際の文字の合流・入力・スクランブル・数値カウント・字別回転・輪郭など。文字以外には移動・マスク等の外側の動きを適用。004には数値を含む文字が必要|
|005–008、025–034|配置済みレイヤーをカード/工程として時間差・接続・走査・比較境界・入替。グラフや工程線は装飾で、業務データや画像内の数値を解析しない。033は重ねた前後素材に境界を適用すると比較表現になる|
|009–012、035–040|トンネル・パース・回転・ズーム・パララックス・ぼかしなどの2.5D近似。本物の3Dモデル・深度解析・自動追跡ではない。012はコマの緩急も強さへ反映|
|013、041–048|現在のコマ/レイヤーへの切り込み・円/斜め/インク境界・フリップ・タイル・シャッター・光・形状マスク。前後の別シーンを同時に重ねる高度なトランジションは未実装|
|014–016、049–056|固定シード粒子・紙吹雪・光跡・ネオン・走査・色面・ワープ・リング等。055はタイルマスクと変形による再構築近似で、素材を本物の3D破片へ分割しない|
|057–060|フレームで定めた模擬拍・パルス・バー・ヒット。既定の120 BPM想定。読み込んだBGMの周波数解析や自動ビート検出はしない|

文字の動きが既存のマスクリビールに隠されないよう、文字列を変える効果と外側のマスク/変形を分離した。見本再生可・素材用版を適用可・MP4書出可の区別は維持し、MP4書出は全件未対応と表示する。

## 完成MP4と編集データ

完成MP4では元の文字・背景・演出がひとつに焼き込まれている。元の文字だけを選んで修正することはできない。動画として切り分けたり、上に別の文字を重ねたりする編集になる。元から別々の文字・画像として編集したい場合は素材付きプロジェクト、または元の制作データの変換が必要。今回は元のpromo-studio案件全般を完全自動変換する機能は作っていない。

ブラウザ設定は `workspace/projects/<projectId>/project.json` とassets/へ保存。JSON出力も可能。Codex/Cursorで追加制作する場合はそのプロジェクトフォルダと共通Compositionを参照する。試着・確認に戻る必要はないが、最終MP4書出はRendererの接続・検証が別途必要。

## 変更ファイル

- `src/motion-engine.ts`：60 IDの時間・変形定義。`MotionFrame.tsx`：字別描画・SVG効果・タイルマスク。
- `src/LiveComposition.tsx`：Scene/Layerへの共通描画。`Composition.tsx`は互換入口。
- `src/App.tsx` / `MotionCatalog.tsx`：自動プレビュー、適用先、試着の連結、全60選択、動画編集の入口。
- `src/MovieLibrary.tsx` / `server/library.mjs`：完成動画一覧・コピー取り込み・素材付きサンプル。
- `src/clip-edit.ts`：非破壊分割。右クリップの元動画開始位置・モーション経過を引き継ぎ、総尺を維持。
- `src/core.ts`：Scene motionStackの後方互換schemaアダプター、全60検査、映像範囲の警告、AI部分パッチのsetSceneMotionStack対応。
- `MediaLibrary.tsx`：アップロード動画の全尺コマ化。字の背景帯・字幕色・動画音声の設定も追加。

既存パッケージのみを使用。新規インストールなし。サーバー内のffprobe/ffmpegは既存promo-studio専用バイナリを絶対パスで起動し、windowsHideを指定。配信はlocalhost限定。
