# UI・操作監査

確認日：2026-11-14  
対象：`ai-promo-editor` のローカル編集画面と `/guide/`。編集対象は `sample-d041aeef-bcf`。

## 結果

編集画面には、プロジェクト管理、5つの左パネル、中央プレビューと再生操作、3つの編集対象タブ、設定検索、シーン・レイヤー編集、素材・モーション選択、AI部分修正、引き継ぎ履歴がある。既存ガイドは基本手順とスクリーンショットを持っていたが、やりたい操作から探す検索、カテゴリ絞り込み、画面マップ、用語の区別、操作ごとの条件・変更範囲・保存／取り消し方法・実装状況は欠けていた。既存の `/guide/` を拡張し、入口を増やさずに補った。

ガイドは40件の操作項目、9カテゴリ、同義語検索、よく使う操作、画面マップ、用語集、対応範囲を含む。個々の詳細には画面上の場所、表示条件、変更範囲、手順、保存・戻し方、対応状況、根拠となるソースを記載した。カテゴリや検索語に一致する操作が0件の場合は、前の操作詳細を誤って残さず空状態を表示する。

## 重要な対象の区別

- **テキストの中央揃え**：テキストボックス内の文字列揃えを指す。現行の編集UIには設定項目がない。
- **文字レイヤーの中央配置**：ボックスそのものをキャンバス中央へ移動する操作。テキスト揃えとは別。
- **フレーム**：静止画1枚を指す場合と、素材を表示する枠・マスクを指す場合がある。ガイドでは「映像フレーム」「画像／動画フレーム」と言い分ける。
- **背景／全画面**：素材を画面に広げて背面に置く表示方法。全体配色とは異なる。
- **動き**：A系のアニメーション試着とM系Motion Atlasは別の仕組み。どちらも編集プレビューの動作確認であり、完成動画出力ではない。
- **ドラッグ操作**：編集モードで単一レイヤーを選択・移動。Shiftで比率維持、Altでスナップ解除。角ハンドルでサイズ、回転ハンドルで角度を調整する。
- **文字の行間／複数選択**：現行UIに編集コントロールがない。

## 画面表示の条件

設定パネルの内容は、右側で選んだ「コマ／レイヤー／全体」、レイヤー種別、現在の設定、選択状態に応じて変わる。レイヤーを選んでいないと、レイヤー専用の書式や配置設定が見えない。動画や音声の設定は対象メディアを選択した場合に現れる。設定セクションは開閉式で、設定検索から該当項目を探せる。パネルの開閉状態はプロジェクトデータやUndo履歴に保存されない。

## 実ブラウザー検証

`tests/guide-browser.cjs` をローカルアプリ `http://127.0.0.1:4319` で実行した。確認項目は、編集画面から既存ガイドへのリンク、40項目以上の検索カタログ、文字揃えとボックス配置の同義語検索、手順と条件の表示、画面マップからの詳細遷移、MP4未対応の表示、デスクトップ／390px幅のモバイル表示、ブラウザー例外なし、検査前後の `sample-d041aeef-bcf` のプロジェクトJSON不変である。結果は `docs/qa/ui-guide/result.json`、画面記録は `docs/qa/ui-guide/guide-desktop.png` と `guide-mobile.png`。

この確認は操作ガイド閲覧によって編集中のプロジェクトが変化しないことを検証する。保存、削除、素材編集など全編集機能を自動操作して網羅的に回帰試験した結果ではない。

## ガイド掲載の実装状況

| 表示 | 意味 |
|---|---|
| 利用可 | UIから現在操作できる |
| 条件付き | 選択・素材種別・設定などの前提を満たすと利用できる |
| 未対応 | 利用者が操作するUI／出力経路が現時点でない |
| 未確認 | 根拠を確認できていない（推測で利用可能と案内しない） |

主要な未対応事項は、編集画面からの完成MP4書き出し、テキストボックス内の文字揃え設定、行間設定、複数レイヤー選択である。既存の完成動画の取り込みは別素材としてプレビュー・配置できる機能と、編集可能なプロジェクトへの変換を区別して案内する。
