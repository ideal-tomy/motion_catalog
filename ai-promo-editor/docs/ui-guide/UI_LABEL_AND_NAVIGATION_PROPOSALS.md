# UI名称・ナビゲーション改善案

確認日：2026-11-14。現行画面を調査してまとめた提案で、アプリの表示名や動作は変更していない。

## 表示名の候補

| 現在の名称・表現 | 提案 | 理由 |
|---|---|---|
| コマ | シーン（コマ） | 動画編集に馴染みのある「シーン」を先に示し、既存用語も残す |
| 尺 | 表示時間（尺） | 時間の長さを直感的に理解できる |
| 素材 | 素材ライブラリ | 追加・検索・再利用する場所だと分かる |
| 素材・枠内表示 | 素材の配置・見せ方 | 素材ファイル自体と画面上の表示設定を区別する |
| フレーム | 画像／動画フレーム（枠） | 時間の1コマである映像フレームとの混同を避ける |
| 配置・サイズ | 位置・大きさ・整列 | 画面上でできる操作を具体的に示す |
| 全体 | プロジェクト全体 | 「全画面表示」と受け取られないよう編集対象だと示す |
| 動き | アニメーション・モーション | 2つの動き機能を探しやすくする |
| 固定 | 編集ロック | 編集操作を防ぐ状態だと説明する |
| この再生位置でコマを分割 | ここでシーンを分割 | 操作対象と実行タイミングを短く示す |

## 操作説明で明示する区別

- 「文字を中央揃え」と「文字ボックスを画面中央へ配置」は別操作。現在UIでは後者のみ可能。
- 「全体配色」と「画像・動画を全画面／背景に配置」は別操作。
- 「プレビュー再生」「編集データの保存」「完成MP4の生成」は別工程。現行アプリはMP4生成に未接続。
- A系アニメーションとM系Motion Atlasは名称・適用範囲・試着方法を分ける。
- 「フレーム」は文章中で意味を補う。ボタン名を変更する場合も、既存利用者が迷わないよう初期は括弧書きを併記する。

## ナビゲーション改善案

1. 左パネル名と右設定の見出しは、ガイド内の名称を実画面の表記と一致させる。名称変更を実装する場合は、既存ガイド・検索別名・ツールチップも同時に更新する。
2. 画面マップと検索は維持し、条件で隠れる設定について「どの対象を選ぶと出るか」を設定名の近くに示す。
3. 右パネルの対象タブ（コマ／レイヤー／全体）に現在選択中の対象を明示し、未選択時には「先にキャンバス上の要素を選択」と案内する。
4. Motion Atlasとアニメーションを、左パネル内で別グループとして表示する。試着、取消、採用、完成動画出力の状態も個別に表示する。
5. ドラッグ・サイズ変更・回転・スナップの操作ヒントを編集モード時に短く提示し、キーボードのAlt／Shiftの意味をヘルプから確認できるようにする。

優先順位は、誤操作を招く用語（フレーム、全体、中央揃え）を先に明確化し、その後にパネルの再分類と操作ヒントを検討する。名称・ナビゲーションの変更自体は今回の作業範囲に含めていない。
