# Codexへの依頼文｜MOTION ATLAS 60から動画素材を制作する

## このプロジェクトの目的

現在 `index.html` で60種類のモーション試作品をプレビューできる。これらのモーションIDと演出仕様を変更せず、必要な演出をRemotion / Reactで再利用可能なコンポーネントへ移植し、10〜20秒のCMを出力したい。

## 最初に確認すること

1. `motions.json` / `PROMPTS_60.md` / `index.html` を読み、ID・仕様・2秒プレビューを把握する。
2. 既存のAXEON・ideal・トーナメント等の本番リポジトリを勝手に変更せず、**独立リポジトリ**を作る。
3. 制作対象ID、映像の用途、色、文字、秒数、BGMの入力パスを確認する。未指定の場合はダミー素材と仮のコピーを使い、公式ブランドの実データを捏造しない。

## 共通実装要件

- 1920×1080 / 30fps / sRGB を標準に、縦長9:16へ拡張できること。
- `src/motions/M001/` のように一つずつ独立部品として実装。
- 各モーションが `progress` / `frame` と `durationInFrames` から決定論的に表示を決めること。
- text / theme / speed / easing / startFrame / endFrame / audioCue を props 化。
- 組み合わせ作品と単体プレビューで同じ定義を参照すること。
- BGM、効果音の使用権利を確認。音楽のテンポやヒット位置に対してタイムコードを使って同期。
- フォントは配布権・ライセンスを確認し、フォントファイルを成果物に含めない。
- 文字が読める静止時間を確保し、発光・点滅・画面酔い・スマホでの可読性を確認。

## 最初のテスト制作（サンプル）

用途: ダーツトーナメント用、20秒のオープニング。

| 秒数 | ID | 動き | 役割 |
|---|---|---|---|
| 0〜3秒 | M-009 | トンネル | 舞台への没入 |
| 3〜6秒 | M-017 | タイプライター | トーナメント名登場 |
| 6〜10秒 | M-060 | VSヒット | 対戦演出と効果音同期 |
| 10〜13秒 | M-054 | リング | 対戦カード確定 |
| 13〜17秒 | M-014 | パーティクル | 山場 |
| 17〜20秒 | M-016 | セレブレーション | 締め |

各シーンの開始・終了フレーム・表示テキスト・音声キューを一覧で管理し、シークで破綻しない実装にする。

## 完了条件

- ブラウザ上で各IDの単体プレビューができる。
- 映像の構成をJSON等で宣言して差し替えられる。
- 指定モーションで20秒作品を組み立て、H.264 MP4として書き出せる。
- README、実装対象一覧、制約・依存関係、テスト結果をMarkdownで提出する。
