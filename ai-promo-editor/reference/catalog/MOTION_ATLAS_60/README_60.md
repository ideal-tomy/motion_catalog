# MOTION ATLAS 60｜動く見本＋再利用できるモーション指示文

- バージョン: v0.2 / 2026-11-11
- 目的: CM・広告・トーナメント演出・業務デモで使うモーションを見て選び、ID単位で依頼する
- 収録: **60種類**（既存16＋新規44）／6カテゴリー
- 技術: ブラウザ単体で再生できる Canvas 2D 試作品

## まず使ってみる

1. `index.html` をブラウザで開く（ネット接続不要）。
2. 下のカテゴリ／検索で見たい動きを探し、カードをタップして単体プレビュー。
3. 好きな動きを右側で「依頼文をコピー」する。
4. 複数を組み合わせたい場合は「＋ 組み合わせに追加」→「選択分を一括コピー」。
5. モーション番号（例: `M-060`）を制作指示書に記載しておく。

`motion_catalog_60.jpg` は全60種を同じ時間位置で切り出した静止一覧。
`motion_atlas_showreel_20s.mp4` は**前の16種から10カットを組んだ20秒動画**。新規44種はこのMP4には含まれず、HTML図鑑で動きを確認する。

## 収録数

| カテゴリー | 収録数 | 代表的な用途 |
|---|---:|---|
| 文字 | 12 | 商品名、キャッチコピー、KPI |
| UI | 14 | SaaS、製造業の業務デモ、機能紹介 |
| カメラ・奥行き | 10 | イントロ、空間移動、主役の強調 |
| 場面転換 | 8 | テンポのあるカットチェンジ |
| エフェクト | 12 | 勝者、ペア確定、ロゴ登場 |
| 音との同期 | 4 | ビート、ヒット音、BGMに合わせた演出 |

## 仕様の限界と注意点

- **60件すべて違う時間駆動の描画処理**を用意したが、完成したプロ用映像素材ではなく検証用の動く見本。
- 3DカメラなどはCanvasでの疑似表現。製品映像としての本格3DはThree.js等で別途実装が必要。
- 「音との同期」4件は模擬ビートで動く例。マイク入力・音源の周波数解析は実装していない。
- BGM付きなのは付属の20秒ショーリール。図鑑の単体再生ではBGMは流れない。
- 見本上の数値・成果は演出用ダミーであり、営業資料の実績に流用しない。
- 光が激しく点滅する演出は短くし、字幕や主役の読みやすさを確保する。

## 実用的な組み合わせ例

**ダーツトーナメント／対戦直前（約15〜20秒）**: `M-009` トンネル → `M-022` スタンプ → `M-060` VSヒット → `M-054` エネルギーリング → `M-016` セレブレーション。音源のヒットに合わせる。

**AXEON／業務システムCM（約15〜20秒）**: `M-017` タイピング → `M-025` 機能リスト → `M-031` ワークフロー → `M-032` データ連携 → `M-033` ビフォー／アフター → `M-020` 締めの見出し。情報の正確さと読みやすさを優先する。

**製造業／受入検査の紹介（約15秒）**: `M-008` スキャン → `M-026` ステップ進捗 → `M-029` トグル連動 → `M-004` KPI → `M-041` 場面転換。検査精度などの架空データを実績に見せない。

## 再利用用のフォルダー

- `prompts/M-001.md` 〜 `prompts/M-060.md`: 60個の独立依頼文
- `PROMPTS_60.md`: 一括閲覧用
- `motions.json`: カテゴリ・名称・実装イメージ・IDの機械可読データ
- `Codex_制作依頼.md`: 新しい動画やRemotionライブラリを構築する依頼テンプレート

## 制作のすすめ方

「60個を一度にCMで使う」のではなく、**1本の10〜20秒のCMには3〜6個程度を目的に合わせて選ぶ**。各モーションの長さ、表示文字、色、静止時間、BGMのヒット時刻を指定し、単体部品と完成動画を同じ定義から組み立てる。
