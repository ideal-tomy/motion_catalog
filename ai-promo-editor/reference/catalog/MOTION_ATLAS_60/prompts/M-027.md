# M-027｜タブ・スイッチ

- カテゴリー: UI・操作画面
- 参考時間: 0.7〜1.7秒
- 使用例: デモ画面・比較タブ
- 実装候補: SVG / React / Remotion
- 動き: タブの下線が滑らかに移動し、内容パネルが横方向の短いスライドで切り替わる。
