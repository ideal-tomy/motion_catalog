# M-059｜スペクトラム・バー

- カテゴリー: 音との同期
- 参考時間: 1.0〜2.0秒
- 使用例: BGM可視化・待機画面
- 実装候補: Remotion / Web Audio / time-coded cues
- 動き: 帯域ごとの高さを模した多数のバーが音楽に合わせて動き、左右対称に発光する。

**Codex / AI に渡す指示文**

> 帯域ごとの高さを模した多数のバーが音楽に合わせて動き、左右対称に発光する。 画面比率16:9、約2秒の単体モーションとして実装する。0〜1のprogressまたは経過フレームだけから状態を決定し、再生・停止・シークで再現性を保証。背景・フォント・色・速さをpropsで変更できるようにし、終了後に読める静止状態を確保。 このプレビューは模擬ビート同期。実制作時には選定したBGMのBPM・ヒット位置をタイムコードで指定して同期する。
>
> 共通条件：独立したモーションコンポーネントにし、`id: "M-059"` を保持。秒数、テキスト、テーマ色、開始フレームを外から設定できる設計にする。Canvasの描画だけでなく、必要に応じてReact/Remotion版へ移植する。プレビューと最終書き出しで見た目が一致するよう時刻駆動で描画する。
