# M-003｜マスク・リビール

- カテゴリー: 文字
- 参考時間: 0.5〜1.4秒
- 使用例: 価値提案・章タイトル・ロゴ登場
- 実装候補: CSS clip-path / GSAP / Remotion
- 動き: スリットや細い矩形の奥から文字が現れる、整ったタイトル演出。

**Codex / AI に渡す指示文**

> タイトルの文字をマスク領域の内側から上方向にスライドして表示する。3行を0.1秒ずつ遅延し、各行の出現は0.65秒。マスク外には文字を描画しない。見出しの座標、行間、フォントサイズは再利用可能なpropsで指定する。
>
> 共通条件：独立したモーションコンポーネントにし、`id: "M-003"` を保持。秒数、テキスト、テーマ色、開始フレームを外から設定できる設計にする。Canvasの描画だけでなく、必要に応じてReact/Remotion版へ移植する。プレビューと最終書き出しで見た目が一致するよう時刻駆動で描画する。
