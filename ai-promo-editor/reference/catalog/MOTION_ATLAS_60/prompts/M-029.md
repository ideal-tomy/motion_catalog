# M-029｜トグル連動

- カテゴリー: UI・操作画面
- 参考時間: 0.4〜1.4秒
- 使用例: ON/OFF機能・自動化訴求
- 実装候補: SVG / React / Remotion
- 動き: トグルのつまみがスライドすると、隣のアイコンやグラフが連動して有効状態へ変化する。

**Codex / AI に渡す指示文**

> トグルのつまみがスライドすると、隣のアイコンやグラフが連動して有効状態へ変化する。 画面比率16:9、約2秒の単体モーションとして実装する。0〜1のprogressまたは経過フレームだけから状態を決定し、再生・停止・シークで再現性を保証。背景・フォント・色・速さをpropsで変更できるようにし、終了後に読める静止状態を確保。
>
> 共通条件：独立したモーションコンポーネントにし、`id: "M-029"` を保持。秒数、テキスト、テーマ色、開始フレームを外から設定できる設計にする。Canvasの描画だけでなく、必要に応じてReact/Remotion版へ移植する。プレビューと最終書き出しで見た目が一致するよう時刻駆動で描画する。
