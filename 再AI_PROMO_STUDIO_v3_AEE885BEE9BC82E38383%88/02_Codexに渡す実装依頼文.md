# Codex / Cursorへの実装依頼｜AI PROMO STUDIO v3

あなたは、**すでにローカルで稼働している** AI PROMO STUDIO を改修するエンジニアです。アプリの新規作成や全面リライトではありません。添付の `01_機能拡張仕様_モーション素材_レイアウト.md` を最初にすべて確認してください。

## 今回の目的と順番

**第1優先：モーションと画像の内容が見て分かること**

- 現在の「動き」タブには60種類の名前が並ぶが、名前だけでは動きを判断できない。既存の `MOTION_ATLAS_60/index.html` を探し、その本物のCanvas描画を利用して、IDごとに2秒程度のプレビューが動くモーション図鑑を組み込んでください。
- 動く見本は単なる文字の点滅や共通アニメーションに置き換えず、元の60種の違いが分かるものにしてください。
- 一覧は静止サムネイルを基本とし、クリック/タップすると**選んだモーションだけ**拡大再生。再生/停止/再再生を付けてください。60個の常時アニメーションやiframeを作らないこと。
- 既存 `M-001`〜`M-060` とタグデータを保持してください。
- `見本再生可 / シーン適用可 / MP4書出可` を別々に表示。見本のみのものを挿入可能だと偽らないこと。
- 「素材」タブでは画像アップロード後の実サムネイル、クリック拡大、動画ポスター表示を実装。ファイル名だけのカードは禁止。アップロード後のページ再読み込みでも素材が見えるようにしてください。

**第2優先：画面構成のバリエーション**

- 12種類のレイアウトテンプレートをサムネイル一覧から選べるようにしてください（L-01〜L-12。詳細は仕様書）。
- 現在の選択コマに「試着」→「採用/キャンセル」を実装してください。テンプレート切替時に既存画像やテキストを削除しないでください。
- 別コマの配置、タイムライン、秒数を勝手に変更しないでください。

**第3優先：PowerPoint風の直接編集**

- 中央のプレビューに `編集 / 再生` の切替を追加。
- 編集時に長方形、円/楕円、ひし形、テキスト、画像/動画フレームを追加。
- マウス操作で移動、サイズ変更、回転、重ね順変更、複製、削除、ロック。素材を円・ひし形に**切り抜いて**表示可能にする。
- 操作ライブラリとして React Moveable 等の使用を検討して良い。ただし編集UIと出力用描画を分離し、枠線やハンドルを動画に含めないこと。
- 編集結果はProject/Scene/Layerの保存データに入れ、Undo/Redo・再読込できるようにしてください。MP4は編集のたびに出力しないでください。

2. 既存の画面、コマ、保存ロジック、モーション接続、出力経路をコードで調査。

## データとプレビューの重要原則

- 動画制作内容をscene/layersのJSONに保持する。レイアウトは初期配置のテンプレートであり、自由編集が可能。
- 位置やサイズは16:9の論理座標または正規化座標で管理し、ウィンドウサイズ依存のピクセル値をそのまま保存しない。
- 動画プレビューと書出は同じシーン定義を使用。モーションはフレームから決定的に描画する。
- 元のAtlas Canvas動画が図鑑で再生できても、Remotionでの出力に対応するまでは「出力対応」と表示しない。
- AI再依頼で手動確定済みの別コマを上書きしない。AI変更は部分パッチ→差分確認→承認とする。
- 画像や動画をBase64文字列として巨大なJSONに埋め込まない。素材IDと永続保管先を対応させる。

## 動作確認をすること

- 元Atlasの M-001/M-008/M-020 等のプレビューが実際に異なって見えること。
- 2つのアップロード画像が見分けられ、任意1枚を現在のコマへ配置できること。再読込でも復元すること。
- 12種類の画面構成サムネイルをクリックすると、今のコマだけ見た目が変わること。
- 4分割の1領域を円形に変え、素材をクリップし、大きさと位置を調整して保存・再読込できること。
- 既存のUndo/Redo、秒数、保存、タイムラインが壊れていないこと。
- 図鑑を開いたまま60件すべてが高負荷で動き続けないこと。
- 実際のPCブラウザで編集モードと再生モード、スクロール・クリック誤動作を検証すること。
