# UI/UX再設計（実装前）

## 大枠とワイヤーフレーム

```text
名前 / 保存状態 / Undo / Redo / 保存 / 案件操作
状態メッセージ
┌ 左：構成/素材/動き/AI/引継 ┬ 中央：ライブプレビュー ┬ 右：選択対象・設定検索 ┐
│ コマ一覧（優先）          │ 編集/再生・試着採用取消 │ コマ / レイヤー / 全体│
│ ▸管理 ▸制作依頼 ▸履歴    │ 素材・文字を直接選択    │ よく使う設定          │
│ 素材検索→配置操作         │ プレビュー寸法を安定    │ ▸値の要約付き設定群   │
└──────────────────────────┴───────────────────────┴──────────────────────┘
下：コマ時間軸 / 再生位置 / ▸選択コマのアニメーション詳細
```

1366×768では中央の高さを優先し、ヘッダーを整理。1100px程度は列幅を縮めず、左右パネルの表示切替を用意する。画面全体をスクロールさせず、左右の縦スクロールはそれぞれの中に収める。中央は映像を収め、操作バーと時間軸を見失わない。タッチでは主要ボタン・summaryを36〜44px以上にする。

## 文脈と初期表示

- コマを選ぶと「コマ」文脈。尺と画面構成を常時表示し、コマの動き・配色・管理は閉じる。
- 中央/右のレイヤーを選ぶと「レイヤー」文脈。上部に種類・名称・ID、表示/固定状態を表示。文字なら本文・書式、画像/動画なら素材・枠内表示、図形なら形状と色を主要項目として開く。
- 配置・サイズ、動き・タイミング、表示時間、レイヤー管理を共通セクションにまとめる。旧M演出は動きの詳細として残す。
- 「全体」は配色・BGMの状態と素材からの配置導線。未実装の音声機能やMP4出力を実装済みに見せない。
- 一覧・レイヤー追加は選択の入口として常時到達可能。選択ドロップダウンを固定見出しに置く。
- 「設定を探す」は定義したキーワードから所属文脈とセクションを開く。フォームを複製しない。

## 共通セクション

`SettingsSection` を最初に実装する。標準details/summaryを使い、Enter/Space/タッチ、openのアクセシビリティをブラウザ標準で提供。閉じても子は維持する。開閉はsessionStorage内のUI専用キーで管理し、作品JSON・revision・Undo履歴へ入れない。文脈種別ごとに開閉を記憶する。閉じた見出しに尺・レイアウト・動き件数・マスク・配色等の要約を付ける。

選択変更による強制的なscrollIntoViewは避ける。ユーザーが「動きへ」「設定を探す」を押した場合だけ目的セクションを開き、右パネル内で近い位置へ移動。動き選択後は編集項目が開いた状態で保持。見本はカタログを開いたときの1件だけ再生。

## 旧→新の移行

全項目の対応表は [UIUX_AUDIT.md](UIUX_AUDIT.md) の棚卸し表を正本とする。同じ保存値を編集するマスクの重複を統合。動画のトリム秒を主要に、フレーム値を詳細に置く。既存ラベルと保存ハンドラーを再利用する。

|目的|変更前|変更後|
|---|---|---|
|文字を直す|コマ設定→レイヤー選択→長い設定を通過→本文|文字選択→本文（0回の見出し展開）|
|タイプライターを試す|レイヤー一覧→Aフォーム→カタログ→試着|文字選択→動き見出し→追加→カタログ→試着|
|円形素材の中を拡大|レイヤー選択→Aフォームを通過→素材ズーム|画像選択→素材・枠内表示→拡大率|
|コマの秒数|右のコマ設定を上へ探す|コマ選択→常時表示の秒数|
|全体の配色|右の最下部までスクロール|全体→配色（1クリック）|
|素材の差し替え|全素材の配置ボタンを探す|素材検索→対象素材の配置操作→選択枠へ|

## 状態・保存のルール

- 選択ID・作品データ・試着/採用・保存API・Undo/Redoの意味を変更しない。
- UI開閉/文脈/検索は作品データとは分離。開閉だけで未保存表示にしない。
- 開閉しても入力を維持。コマを移動して戻ると確定した編集値を再表示。保存・再読込は既存JSONを正本とする。
- タイムラインはコマ選択とシークを維持し、アニメーション詳細は初期閉。開いても中央を押し下げず、フッターに制限を設ける。

## 実装順と影響ファイル

1. 共通SettingsSectionとUI状態管理。
2. Appの右側をコマ・文字で確認。その後、画像/図形/動画/動きへ展開。
3. 左の構成、素材検索/配置、AI依頼/提案、引き継ぎを共通ルールへ。
4. styles.cssの固定グリッド、狭幅切替、用語・余白・選択表示。
5. 既存テストをセクションを開く操作へ更新し、操作・表示・保存を実ブラウザで検証。

描画エンジン、データスキーマ、既存モーションIDは変更しない。優先必須は文脈・設定群・固定プレビュー・保存回帰。バーのドラッグ、MP4接続、音声機能拡張は今回の対象外。
