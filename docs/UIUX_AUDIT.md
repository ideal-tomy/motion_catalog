# AI PROMO STUDIO UI/UX監査（実装前）

2026-11-13。対象は既存 ai-promo-editor v0.7。React 19、Remotion 4、Vite、ローカルExpress。Appが作品・選択ID・試着・Undo/Redoを管理し、APIへrevision付きJSONを保存する。既存案件9件を含むsrc/server/projectsを `ai-promo-editor/docs/backups/uiux-before-20261113/` に保護した。git statusを確認し、既存の未コミット差分（EditStageの選択・モーダル制御を含む）を維持する。reset/revertは行わない。

## 調査範囲と証跡

実ブラウザで1920×1080、1366×768、1100×800を表示し、構成・素材・動き・AI部分修正・修正メモ／引き継ぎ、動画ライブラリ、M図鑑を操作した。変更前画像と寸法は `ai-promo-editor/docs/qa/uiux/before-*`。設定名は全9画面コンポーネントの属性から列挙し `control-inventory.json` に保存する。既存の15操作群の回帰テストを複製案件で実行し、編集・保存・AI差分・アップロードの基準とする。元案件を操作試験で編集しない。
