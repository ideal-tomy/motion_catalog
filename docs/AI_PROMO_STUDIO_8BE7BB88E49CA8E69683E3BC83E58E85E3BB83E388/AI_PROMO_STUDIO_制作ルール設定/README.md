# AI PROMO STUDIO｜動画制作標準ルール導入セット

> このフォルダは制作アプリのワークフロー機能を実装するための導入用資料です。個別動画制作の正本は[動画制作基準](../../動画制作基準.md)です。通常の動画制作では本フォルダ内のサンプルを追加で読まないでください。

既存のAI PROMO STUDIOに「調査 → 企画 → 絵コンテ → 仮制作 → 品質確認・書き出し」のワークフローを追加するための設計・依頼資料です。

## ファイル
- `docs/VIDEO_PRODUCTION_POLICY.md`：人とAIが共通で使う動画制作のルール
- `config/video-production-workflow.yaml`：ワークフローの機械可読な初期定義例
- `AGENTS_追記例.md`：既存AGENTS.mdに追記する短い指示
- `Codex_制作ルール導入依頼.md`：Codexに調査・実装・テストを依頼する本文

## 導入
1. 開発リポジトリの既存の `docs` や `config` と衝突しないか確認し、ルールファイルを配置する。
2. `AGENTS_追記例.md` の内容を既存 `AGENTS.md` に統合する（上書きしない）。
3. `Codex_制作ルール導入依頼.md` をCodexに渡す。
4. Codexにまず現状の保存・生成・プレビュー・レンダリングの構成を調査させ、その後に各工程のUIとステージ管理を実装させる。

このセットはルール・設定のサンプルであり、既存アプリに導入された状態ではありません。YAMLに記述した項目は実装側で解釈する必要があります。
