# 既存 `AGENTS.md` に追記する例

> このファイルをそのまま `AGENTS.md` に上書きしないこと。既存の内容がある場合は、下記の「追記内容」だけを末尾に加える。

## 追記内容

```markdown
## AI PROMO STUDIO｜動画制作の標準ワークフロー

新規プロモーション動画の依頼・全面再企画を受けたら、実装前に必ず `docs/VIDEO_PRODUCTION_POLICY.md` を読む。
アプリの動画制作フローは `config/video-production-workflow.yaml` を基準とする。

進め方：製品・デモ調査 → 訴求と異なる企画案の提示 → 絵コンテ → 承認 → 動くプレビュー → 最終書き出し。
商品価値の根拠を確認せず事実として広告表現しない。スクショの単純な連続配置を完成品としない。
各シーンに目的・根拠・見せたい操作・視線誘導・モーション採用理由を持たせる。
手動確定した編集を壊さない。局所修正では全工程を繰り返さず影響範囲だけ更新する。
動画制作機能のコードを変更するときは、ステージ遷移と承認条件が守られることをテストする。
```

**重要**：この `AGENTS.md` はCodexの開発行動を方向付ける補助策。**実際の利用時にアプリのAI生成が工程を必ず通るかどうかは、アプリ側のワークフロー制御で保証する**。
