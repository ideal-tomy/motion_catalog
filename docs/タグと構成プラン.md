# タグから構成を選ぶ

## 今回使えるもの

[制作プランを開く](../制作プラン/index.html)。同じ素材について「迫力・落ち着き・緩急」の3案を比較できる。癒しは個別選択。DD高級感版を含む5案件で、全20案を生成している。M-005の追加移植により検証済み部品は17件。

各案に、秒数・見せる機能・強弱の配分・採用した演出・選択理由・除外理由・音と色の方針を表示する。構成JSONは各案件の `planning/` に保存し、画面からダウンロードできる。

**構成案はまだ完成動画ではない。** 既存Compositionへ直接渡せる汎用レンダー形式への統合は次の工程。今回のタグ・素材一覧は既存の完成映像を変更しない。モーションの仮タグが合うか、実際の映像を見てレビューする。

## 情報の所在

| ファイル | 用途 |
|---|---|
| `src/catalog/tag-taxonomy.json` | 印象・強さ・速度・用途・光量・レビュー状態の定義 |
| `src/catalog/style-tags.json` | M-ID60件の初期タグ。編集する正本 |
| `src/catalog/registry.json` | 説明・実装状態・検証証跡とstyleタグを統合した制作側登録情報 |
| `src/catalog/transition-tags.json` | TR-ID9件のタグ。既存M-IDとは区別 |
| `presets/styles.json` | 4つの印象とシーンの尺・強弱の方針 |
| `jobs/<job>/assets.json` | 素材のパス・種類・撮影尺・機能・操作段階・根拠・権利・切り出し状態 |
| `jobs/<job>/planning/*.json` | 素材と演出を選んだ構成候補 |

タグは参照カタログの説明と依頼文から付けた仮分類で、全60件 `tagStatus: provisional`。動作確認済みの16件という状態とは別管理する。タグの印象をレビューしたらstyle-tags.jsonでreviewedへ変える。既存の部品を別の速度や光量で使う場合、その調整後の映像検査も必要。

推薦は `verified` の演出に限定し、仕様変更の再レビュー対象を除外。光量、揺れ、印象、シーンの強さに合わせて絞り込む。癒しは光量low・揺れなし・energy 2以下。緩急は単体タグではなくシーン間の強弱と保持時間で表現する。

素材の縦型切り出し・焦点領域・権利は未確認状態も明記する。元の撮影尺を超える場合は末尾保持が必要と表示し、長い操作動画が存在するようには扱わない。

## 更新手順

```powershell
# promo-studioで実行
# まずstyle-tags.json、assets.json、presets/styles.jsonを編集する
npm run catalog:sync
npm run plan
npm run verify:workflow
```

`setup-planning.mjs` は初期ファイルがない場合だけ作る。レビュー済みタグや版番号を初期値へ戻さない。

次はこの構成案とrequest.jsonの共通スキーマを定め、対応するCompositionを通して新しい機能紹介動画を生成・検査する工程。その後、撮影共通化・縦型へ進む。
