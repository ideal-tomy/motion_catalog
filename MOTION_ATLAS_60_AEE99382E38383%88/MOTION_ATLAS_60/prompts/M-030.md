# M-030｜ドラッグ・スナップ

- カテゴリー: UI・操作画面
- 参考時間: 1.0〜2.3秒
- 使用例: 直感的な操作デモ
- 実装候補: SVG / React / Remotion
- 動き: 要素が指／ポインタに引かれるように移動し、目的エリアに接近すると自動吸着して整列する。

**Codex / AI に渡す指示文**

> 要素が指／ポインタに引かれるように移動し、目的エリアに接近すると自動吸着して整列する。 画面比率16:9、約2秒の単体モーションとして実装する。0〜1のprogressまたは経過フレームだけから状態を決定し、再生・停止・シークで再現性を保証。背景・フォント・色・速さをpropsで変更できるようにし、終了後に読める静止状態を確保。
>
> 共通条件：独立したモーションコンポーネントにし、`id: "M-030"` を保持。秒数、テキスト、テーマ色、開始フレームを外から設定できる設計にする。Canvasの描画だけでなく、必要に応じてReact/Remotion版へ移植する。プレビューと最終書き出しで見た目が一致するよう時刻駆動で描画する。
