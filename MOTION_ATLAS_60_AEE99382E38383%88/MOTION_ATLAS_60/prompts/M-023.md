# M-023｜文字フリップ

- カテゴリー: 文字
- 参考時間: 0.8〜1.8秒
- 使用例: 数字切替・タイトル更新
- 実装候補: Canvas / React / Remotion
- 動き: 各文字が縦軸方向に裏返り、新しい文字列へ切り替わる。回転の途中は表示を小さくして視認性を維持する。

**Codex / AI に渡す指示文**

> 各文字が縦軸方向に裏返り、新しい文字列へ切り替わる。回転の途中は表示を小さくして視認性を維持する。 画面比率16:9、約2秒の単体モーションとして実装する。0〜1のprogressまたは経過フレームだけから状態を決定し、再生・停止・シークで再現性を保証。背景・フォント・色・速さをpropsで変更できるようにし、終了後に読める静止状態を確保。
>
> 共通条件：独立したモーションコンポーネントにし、`id: "M-023"` を保持。秒数、テキスト、テーマ色、開始フレームを外から設定できる設計にする。Canvasの描画だけでなく、必要に応じてReact/Remotion版へ移植する。プレビューと最終書き出しで見た目が一致するよう時刻駆動で描画する。
