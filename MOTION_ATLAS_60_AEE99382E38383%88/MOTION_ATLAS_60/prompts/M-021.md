# M-021｜曲線に沿う文字

- カテゴリー: 文字
- 参考時間: 1.0〜2.8秒
- 使用例: イベント名・周回ロゴ・装飾見出し
- 実装候補: Canvas / React / Remotion
- 動き: 文字列を円弧の接線に沿って配列し、弧が回転して正位置に落ち着く。円弧半径と回転角を調整可能にする。

**Codex / AI に渡す指示文**

> 文字列を円弧の接線に沿って配列し、弧が回転して正位置に落ち着く。円弧半径と回転角を調整可能にする。 画面比率16:9、約2秒の単体モーションとして実装する。0〜1のprogressまたは経過フレームだけから状態を決定し、再生・停止・シークで再現性を保証。背景・フォント・色・速さをpropsで変更できるようにし、終了後に読める静止状態を確保。
>
> 共通条件：独立したモーションコンポーネントにし、`id: "M-021"` を保持。秒数、テキスト、テーマ色、開始フレームを外から設定できる設計にする。Canvasの描画だけでなく、必要に応じてReact/Remotion版へ移植する。プレビューと最終書き出しで見た目が一致するよう時刻駆動で描画する。
