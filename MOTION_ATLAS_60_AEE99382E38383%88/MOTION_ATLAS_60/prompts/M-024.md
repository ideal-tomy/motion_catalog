# M-024｜アウトラインから塗り

- カテゴリー: 文字
- 参考時間: 0.8〜2.0秒
- 使用例: タイトル確定・ロゴ露出
- 実装候補: Canvas / React / Remotion
- 動き: 最初は文字の輪郭線のみを見せ、左から右へ塗り色が浸透して実体化する。

**Codex / AI に渡す指示文**

> 最初は文字の輪郭線のみを見せ、左から右へ塗り色が浸透して実体化する。 画面比率16:9、約2秒の単体モーションとして実装する。0〜1のprogressまたは経過フレームだけから状態を決定し、再生・停止・シークで再現性を保証。背景・フォント・色・速さをpropsで変更できるようにし、終了後に読める静止状態を確保。
>
> 共通条件：独立したモーションコンポーネントにし、`id: "M-024"` を保持。秒数、テキスト、テーマ色、開始フレームを外から設定できる設計にする。Canvasの描画だけでなく、必要に応じてReact/Remotion版へ移植する。プレビューと最終書き出しで見た目が一致するよう時刻駆動で描画する。
