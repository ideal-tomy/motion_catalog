## あなたの役割

あなたは動画制作用Webアプリの実装責任者です。目的は「AIに初稿を依頼し、ブラウザで1コマずつ編集し、確定後にMP4と共有HTMLを生成する**個人向けローカル環境**」を作ることです。

**最重要：** 初稿以降、色・時間・画面分割・文字・モーションの小さな変更でMP4の再生成を要求しない。編集UIが唯一の調整窓口となり、Remotion Playerで即時プレビューし、完成後にレンダリングする。

## 技術方針

- Windows + Node.js 22を想定（利用中Nodeを先に確認）。
- 編集画面：Vite + React + TypeScript。Tailwindは必要な場合のみ。余白過多や意味不明な改行を避ける。
- 映像描画：RemotionのReactコンポジション。`@remotion/player`とレンダーが**同じコンポジション**を共有。
- ローカルAPI：Node + FastifyまたはExpress。`127.0.0.1`のみで待機。
- スキーマ：JSON SchemaあるいはZodで厳格検証。TypeScript型と同期。
- プロジェクト保存：初期段階はJSONファイル + メディアディレクトリ。DB不要。
- 素材撮影：Playwrightを後続で導入。本人の所有・許可済みデモ以外に操作を実行しない。
- 最終MP4：Remotion Renderer / CLI。共有HTMLは動画埋め込みページ＋必要ファイル。
- AI連携：**最初はCodexが初稿JSON／局所patchを出す**。APIキー付き自動AI実行や有料API呼び出しは後で選択可能にする。

## 開発ステップと完了条件

### Step 1｜JSONから同じ映像を表示
- 付属 `examples/example-project.json` をロード。20秒・4シーン・30fpsで構成。
- `project.schema.json` をバリデーション。
- シーンごとに画面を表示するReactコンポジションを実装し、Remotion Playerで全編再生。
- 再生位置でシーンが切り替わり、タイムラインの選択が連動。
- まだMP4レンダリングに進まない。

### Step 2｜ブラウザから編集可能に
- シーン一覧・タイムライン・プレビュー・右側インスペクタを実装。
- 尺、画面分割（single/split2/grid4/free）、文字、色、速度、透明度を変更して即時反映。
- 素材追加のアップロード、レイヤー順変更、テキストの直接編集。
- 7秒→9秒の変更で、20→22秒に伸長するデフォルト挙動。
- 「20秒維持」選択時は再配分案を**承認してから**適用。
- Undo/Redo、保存、再読込。編集値のバリデーション。

### Step 3｜モーションと複合エフェクト
- MOTION ATLAS 60をカタログ表示。既存ID・名称は変更しない。
- 4〜6件（例：M-017 タイピング、M-008 スキャン、M-003 マスクリビール、M-005 カード・カスケード）をRemotionで再実装。**既存JSONと実際のIDが合うことを確認。**
- モーションRegistryと実装状態を設け、`demo-only`を動画に挿入しようとしたらエラー表示。
- 文字にタイプとスキャンを重ねられる。個別の時間・不透明度・速度を編集可能。
- モーションはフレーム時刻だけに依存し、レンダー間で決定論的。ランダムはseed必須。

### Step 4｜色の提案・AI部分編集
- 主色1色→調和したパレット候補、2色→役割分担と使用比率の候補を提示。
- 色提案と適用は別操作。アクセント比率はあくまでガイドとして表示。
- global themeとscene override、手動ロックを実装。
- 外部Codexが生成したpatch JSONをUIでインポート→差分レビュー→承認適用。
- patchは`targetSceneId`と固定操作のホワイトリストで制限。未指定シーンを変えたら拒否。
- baseRevision・locks・JSON Schema・motionRegistryを検証。Undoを必ず効かせる。

### Step 5｜最終出力
- MP4を確定データから1回レンダリング。レンダー中は進捗・失敗理由をUIに表示。
- HTML共有用パッケージを書き出す（動画プレーヤーが中心、秘密データを含めない）。
- プロジェクトJSONと素材のバックアップを保存。
- 音声が無い場合は無音を明示。BGMは提供素材のみ使用し、無断で取得しない。
- カット境界・タイトル・セーフエリア・最終フレーム・尺・音声のQA。

## 手動編集の破壊を防ぐルール

- プロジェクトJSONのシーンは安定IDで参照。配列の並び変更に影響されない。
- AI提案は**差分候補**。直接 `project.json` を上書きしない。
- 適用前に変更前後の差分を明示し、対象シーン以外を変更しない。
- 直接編集した項目、ロックした項目はデフォルト保護。
- 自動提案と手動編集を混ぜて「初稿を再生成して帳消し」は禁止。
- ファイルを保存するときは一時ファイル＋アトミックリネーム等で破損を防ぐ。

## UI要件（優先順位）

1. **中央プレビューが大きく見やすい**。文字羅列・意味不明な余白・不必要な入れ子枠禁止。
2. **下にシーンごとのタイムライン**。変更した位置・尺がすぐわかる。
3. **右に選択シーン／レイヤーの編集**。文字・秒数・レイアウト・色・演出に最短でアクセスできる。
4. **左に素材・モーション検索・AI依頼**。重複操作を避ける。
5. 詳細技術設定は折りたたみ、通常操作では「見た目→結果」に集中させる。
6. 編集UIと動画自体のデザインを分離する。UIの色・ボタン・余白が映像に影響しない。

## 必須の実機テスト（成功するまで完成扱いにしない）

- [ ] 20秒4コマの例がプレビューで見える。
- [ ] 2コマ目を4分割に変更 → 他コマは変わらない。
- [ ] 3コマ目7→9秒 → 全体20→22秒。勝手に別コマを短縮しない。
- [ ] 20秒維持の提案を承認した場合のみ再配分される。
- [ ] 説明テキストにタイプ＋スキャンを**重ねて**表示できる。
- [ ] 主色1色・2色のカラー提案があり、適用後プレビューが更新される。
- [ ] 指定シーンだけAI patch→差分確認→承認。ロック済み値を破壊しない。
- [ ] Undo/Redo、保存・再起動後の復元。
- [ ] MP4とプレーヤーで尺、位置、タイトル、モーション、カラーパレットが一致。
- [ ] 音声有／無の挙動が明示される。
- [ ] HTML共有パッケージが別PCでも再生できる（ファイル一式を同じ階層に置く）。
- [ ] 既存リポジトリ・本番環境・元60カタログは一切変更なし。

## セキュリティ上の禁止事項

- 無断で公開URLにデプロイしない、Cloudflare/Vercel/GitHubの既存プロジェクトを変更しない。
- 実アカウント・顧客情報で自動撮影しない。本番送信・決済・操作をしない。
- ブラウザへAPIキーを渡さない。ローカルAPIを`0.0.0.0`で無防備に公開しない。
- 任意のシェルコマンド、JavaScript、HTMLをAI patchから実行しない。
- 外部素材やサイトのコードをライセンス不明のまま組み込まない。

## 1回目の作業依頼

**まず `Step 1` と `Step 2` を完成させ、Step 3以降を分割して進める。**

最初から本格3Dや全60モーションの移植、AIサービス連携を同時に行わない。編集コアの確実性を優先し、シーン単位の秒数・レイアウト・文字・色が実際にブラウザ上で変更できることを確認する。

**最終的な狙い：** 「新しいデモの紹介動画を依頼→AI初稿をブラウザで開く→コマ単位で微調整→確定したら一回でMP4/HTML出力」を反復できる状態。
