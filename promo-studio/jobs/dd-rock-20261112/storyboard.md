# DD ROCK CUT — 22秒 / 10カット

前回に合わせ、2秒×9カット＋4秒のエンドカード。主役の機能は「給与×勤怠の実突合と根拠確認」だけに絞る。

| 秒 | 画面 | コピー | モーション |
|---|---|---|---|
| 0–2 | 黒・サイバー調の導入 | 数字だけでは、見えない。 | M-002 / M-018 / M-046 |
| 2–4 | サンプル資料投入前の実画面 | 資料を、つなぐ。 | M-028 / M-046 |
| 4–6 | 実際の投入→突合→結果の連番 | 給与 × 勤怠。 | M-008 / M-028 / M-046 |
| 6–8 | SIGNALの文字収束と分割合流 | 違和感を、見逃すな。 | M-002 / M-018 / M-046 |
| 8–10 | 差異3件の実画面 | ズレを、捉える。 | M-028 / M-046 |
| 10–12 | 給与台帳と勤怠データの説明図 | その差には、理由がある。 | M-032 / M-018 / M-046 |
| 12–14 | 根拠ダイアログの実画面 | 根拠まで、たどる。 | M-028 / M-002 / M-046 |
| 14–16 | 元データの参照行に注目 | 元の一行へ。 | M-028 / M-046 |
| 16–18 | 人の判断へ戻すメッセージ | 決めるのは、あなた。 | M-018 / M-002 / M-046 |
| 18–22 | AXEON DD INTELLIGENCE | 見抜く。その先を、決める。 | M-002 / M-018 / M-046 |

黒・アイスブルー・朱色を使用。前回のモーションから全6種類を入れ替え、文字スクランブル、スキャン、分割文字合流、モーダルズーム、データパケット、シャッターを使用。
180 BPM。Dを中心とした低音リフに差し替えたオリジナルのロック調BGM。2秒=6拍の位置に編集ヒットを配置。白い全画面ストロボは使用しない。
実処理の映像は編集しているため、映像上の尺を実務での処理速度として主張しない。
