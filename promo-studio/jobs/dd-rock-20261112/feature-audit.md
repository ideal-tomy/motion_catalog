## 操作とデータ

新規ブラウザコンテキストで /ai → 自社で入力 → 架空の会社名 → 対象企業として設定 → サンプル資料を投入 → 根拠を見る → 発見に戻る。
会社名は「プロモ検証（架空企業）」。金額・人数は画面のデモ初期値を基本とし、売上だけHTMLのmin=1 / step=10に合う2801へ入力した（初期値2800ではブラウザ検証によりフォーム送信できない）。対象ソースを修正せず、UI上の有効な架空入力だけで進めた。
撮影対象の氏名は同梱CSVの架空名。公開ファイルの内容と照合済み。実顧客データや既存ブラウザの保存情報は使わない。

## 本物と演出の区別

- CSVの取得・突合・差異の計算・根拠行表示は元アプリの実処理。
- 処理中の実況は元アプリで420msごとに表示する演出。LLMのライブ解析として見せない。
- 完成動画には「実画面 / 同梱の架空CSVを使用」「意思決定支援デモ・最終判断は人が行います」を常時表示。
- UIの拡大、クロップ、枠、走査線は動画編集による強調。給与／勤怠の接続図は「EXPLANATORY GRAPHIC」と明示した説明図。
- 実績・改善率・債務の確定・解析精度の主張は加えない。
