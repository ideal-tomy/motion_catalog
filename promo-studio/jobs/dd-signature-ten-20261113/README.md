# DD・10コマ／スキャンCM

前作30秒CMへの修正依頼。30秒を3秒×10コマに再構成。2コマ目にカタログ実装M-008のスキャンを1回使用し、実際の照合連続キャプチャと重ねる。前作・完成動画は保持した別作品。

各コマ：ブランド→スキャン照合→差異の輪郭→根拠カード→全体像→バリューアップ画面→結果と根拠→根拠の数値→3画面の対比→ブランド。

9つの切り替えは各18フレーム（0.6秒）、各1回：奥行き通過、横送り、ページ回転、円形開口、縦送り、斜めワイプ、中央の扉が閉じる切り替え、カードの重なり、光学ぼかしのディゾルブ。実際に前後2コマを同時描画して切り替え、暗転の空白は挟まない。

画面内のモーションも各1回：文字間の収束／横長の開口、M-008スキャン、差異の枠線描画、M-028カード展開、パネルのヒンジ、画面内の横移動、比較画面のマスク、根拠への遠近フォーカス、3カードの段差登場、ブランドの罫線。

素材：前作と同じ検証済みDD実画面。出典 `../dd-rock-20261112/captures/evidence.json`。スキャン場面は120枚・4秒の実操作キャプチャを75フレーム（2.5秒）に圧縮し、最後を保持。スキャン線と枠は編集演出で、製品のネイティブUIではない。その他は実画面の静止切り抜き。氏名・数値は架空サンプル。

BGMは前作の30秒オリジナル音源を維持。完成構成はcomposition.jsonとsrc/DdSignatureTen.tsx。planning/は共通プランナーの別案。

再出力：`node scripts/render.mjs jobs/dd-signature-ten-20261113` → `node scripts/qa.cjs jobs/dd-signature-ten-20261113`。フルHD/30fps/900フレーム。QA合格後に命名規則で動画ライブラリへ集約。
