# ROCK CUT — 使用画面・素材監査

対象と機能根拠は `../tournament-20261112/feature-audit.md` を継承。
実画面キャプチャの操作・通信証跡は `../tournament-20261112/captures/evidence.json`。

- draw / vs / result / championの検証済み連番を再使用。今回のために対象アプリへ書き込んでいない。
- サンプル用Animation Previewを広告編集した作品。実際の大会結果や本番操作を撮影した映像ではない。
- 画面の拡大・クロップ・分割・モノクロ化は編集演出。新しいUI機能は創作していない。
- 営業実績、削減率、性能数値、顧客名を含めない。
- 画面の人物は元アプリのサンプル名とプレースホルダー。個人データの追加なし。
- 新規BGMは `scripts/music-rock.mjs` のオリジナル合成。ブランド素材や第三者の音源は含めない。
- 元アプリ内の画像素材の商用利用・第三者配布権については引き続き外部公開前の確認事項。
- Remotionの利用条件の確認記録は初版の監査書を参照。有料契約・公開は実行しない。
