# DD / 高級感・信頼感 — 20秒

指定：理想.md、対象DD（ユーザー確認済み）。横型1920×1080、30fps。低彩度のネイビー・生成り・控えめな金色。余白と静止時間を確保する。

| 秒 | 内容 | 演出 |
|---|---|---|
| 0–3 | 判断を支える、確かな根拠を。 | ネイビーの余白、M-003の段階表示 |
| 3–7 | DD製品・資料入力画面 | 実キャプチャ、M-012の1.8%スローズーム |
| 7–10.5 | 給与×勤怠の照合結果 | 実キャプチャの上部を読みやすくクロップ、M-005の要約カード |
| 10.5–14 | 給与台帳・勤怠の参照行 | 実ダイアログを拡大、1.5%スローズーム |
| 14–20 | AXEON / DD INTELLIGENCE、CTA | 文字の段階表示後に長めの保持。テキストのサービス名を使用 |

シーン境界は約0.53秒のクロスフェード。色調は背景と編集装飾に適用し、実画面の数値と機能は改変しない。カードは「機能の要約」と明示した編集上の説明で、アプリの新UIとして主張しない。

M-003、M-012、M-005の3種類を選択。過剰な光・グリッチ・回転・カメラ揺れは使わない。既存M-012実装は2Dの控えめな拡大であり、実3Dカメラではない。

BGMは第三者録音を使わず、正弦波の倍音で合成した穏やかなピアノ風音とパッド。ロック版の音源は使い回さない。
