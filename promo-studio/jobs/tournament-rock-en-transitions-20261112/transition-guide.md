22秒、10カット。最初の9カットは各2秒、最後は4秒。180 BPMのオリジナル・ロック音源。

- 2秒: TR-001 / fly-through
- 4秒: TR-002 / whip-spin
- 6秒: TR-003 / cube
- 8秒: TR-004 / diagonal
- 10秒: TR-005 / iris
- 12秒: TR-006 / card-flip
- 14秒: TR-007 / split-gate
- 16秒: TR-008 / whip-pan
- 18秒: TR-009 / quad-burst

切り替えは境界の前後9フレーム、計18フレーム。前後の画面を重ねて動かす。通常区間にも緩やかなズームを継続。TRは今回追加した独自トランジションのID。既存カタログIDとは区別。

アプリ画面の日本語は撮影時のDOM上だけで英語化。元アプリのファイルは変更していない。選手名・大会名・勝利表示も英語化し、サンプルデータである旨を英語で表示。
