# M-045｜ピクセル分解

- カテゴリー: 場面転換
- 参考時間: 0.6〜1.4秒
- 使用例: デジタル世界・テック系CM
- 実装候補: Canvas / CSS masking / Remotion
- 動き: 格子状の小さなタイルが時間差で消え、背後の次画面を順に露出する。

**Codex / AI に渡す指示文**

> 格子状の小さなタイルが時間差で消え、背後の次画面を順に露出する。 画面比率16:9、約2秒の単体モーションとして実装する。0〜1のprogressまたは経過フレームだけから状態を決定し、再生・停止・シークで再現性を保証。背景・フォント・色・速さをpropsで変更できるようにし、終了後に読める静止状態を確保。
>
> 共通条件：独立したモーションコンポーネントにし、`id: "M-045"` を保持。秒数、テキスト、テーマ色、開始フレームを外から設定できる設計にする。Canvasの描画だけでなく、必要に応じてReact/Remotion版へ移植する。プレビューと最終書き出しで見た目が一致するよう時刻駆動で描画する。
