# M-032｜データ・パケット流動

- カテゴリー: UI・操作画面
- 参考時間: 1.0〜2.3秒
- 使用例: システム連携・APIデータ
- 実装候補: SVG / React / Remotion
- 動き: 二つのアプリケーション間を小さなデータパケットが移動し、受信側の状態が更新される。

**Codex / AI に渡す指示文**

> 二つのアプリケーション間を小さなデータパケットが移動し、受信側の状態が更新される。 画面比率16:9、約2秒の単体モーションとして実装する。0〜1のprogressまたは経過フレームだけから状態を決定し、再生・停止・シークで再現性を保証。背景・フォント・色・速さをpropsで変更できるようにし、終了後に読める静止状態を確保。
>
> 共通条件：独立したモーションコンポーネントにし、`id: "M-032"` を保持。秒数、テキスト、テーマ色、開始フレームを外から設定できる設計にする。Canvasの描画だけでなく、必要に応じてReact/Remotion版へ移植する。プレビューと最終書き出しで見た目が一致するよう時刻駆動で描画する。
